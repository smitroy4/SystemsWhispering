## 1. Arrays & Hashing

### 1.1 Contains Duplicate
- **Difficulty**: Easy
- **LeetCode**: [217. Contains Duplicate](https://leetcode.com/problems/contains-duplicate/)
- **NeetCode**: [Contains Duplicate](https://neetcode.io/problems/contains-duplicate)
- **Data Structures**: Array, Hash Set
- **Patterns**: Seen Set, Sorting

#### Problem Description
Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

#### Examples

**Example 1**
- **Input**: `nums = [1,2,3,1]`
- **Output**: `true`
- **Explanation**: The value `1` appears at index 0 and index 3.

**Example 2**
- **Input**: `nums = [1,2,3,4]`
- **Output**: `false`
- **Explanation**: All elements are distinct.

#### Constraints
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

#### Intuition
Duplicates are the only thing that matters, not their positions. So the core question is "have I seen this value before?" A set answers that in O(1). Sorting also works, because equal values end up adjacent.

---

##### Approach 1: Brute Force (Nested Loops)

**Intuition**: Compare every pair. If any two are equal, a duplicate exists.

**Algorithm**:
1. For each `i` from `0` to `n-1`.
2. For each `j` from `i+1` to `n-1`.
3. If `nums[i] == nums[j]`, return `true`.
4. Return `false`.

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[i] == nums[j]) {
                    return true;
                }
            }
        }
        return false;
    }
}
```
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$

---

##### Approach 2: Better (Sort, then Check Adjacent)

**Intuition**: After sorting, any duplicate values sit next to each other, so one linear scan of neighbours is enough.

**Algorithm**:
1. Sort `nums`.
2. For each `i` from `1` to `n-1`, if `nums[i] == nums[i-1]`, return `true`.
3. Return `false`.

Note: this sorts the input in place. Copy the array first if the caller needs it unchanged.

```java
import java.util.Arrays;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Arrays.sort(nums);
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] == nums[i - 1]) {
                return true;
            }
        }
        return false;
    }
}
```
- **Time Complexity**: $O(n \log n)$ for the sort
- **Space Complexity**: $O(1)$ extra (Java's dual-pivot quicksort uses $O(\log n)$ stack)

---

##### Approach 3: Optimised (Hash Set, Two Passes)

**Intuition**: Put everything in a set. If the set ends up smaller than the array, some value was inserted twice.

**Algorithm**:
1. Add every element to a `HashSet`.
2. Compare `set.size()` with `nums.length`. If smaller, return `true`.

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) {
            set.add(x);
        }
        return set.size() != nums.length;
    }
}
```
- **Time Complexity**: $O(n)$ average
- **Space Complexity**: $O(n)$

---

##### Approach 4: Best (Hash Set, Single Pass with Early Exit)

**Intuition**: `Set.add` returns `false` when the element is already present. So the duplicate can be detected during insertion, and we can stop immediately.

**Algorithm**:
1. For each `x` in `nums`, if `seen.add(x)` returns `false`, return `true`.
2. Return `false`.

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            if (!seen.add(x)) {
                return true;
            }
        }
        return false;
    }
}
```
- **Time Complexity**: $O(n)$ average, and it can exit early
- **Space Complexity**: $O(n)$

### 1.2 Valid Anagram
- **Difficulty**: Easy
- **LeetCode**: [242. Valid Anagram](https://leetcode.com/problems/valid-anagram/)
- **NeetCode**: [Valid Anagram](https://neetcode.io/problems/is-anagram)
- **Data Structures**: String, Hash Table, Array
- **Patterns**: Character Frequency Count

#### Problem Description
Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

An anagram is a word formed by rearranging the letters of another word, using every letter exactly once.

#### Examples

**Example 1**
- **Input**: `s = "anagram"`, `t = "nagaram"`
- **Output**: `true`
- **Explanation**: Both strings have three `a`s, one `g`, one `m`, one `n`, and one `r`.

**Example 2**
- **Input**: `s = "rat"`, `t = "car"`
- **Output**: `false`
- **Explanation**: `t` contains `c`, which `s` does not.

#### Constraints
- `1 <= s.length, t.length <= 5 * 10^4`
- `s` and `t` consist of lowercase English letters.

#### Intuition
Two strings are anagrams exactly when they have the same character frequencies. Lengths must match first. Then you need a way to compare multisets of characters. Since the alphabet is fixed at 26 lowercase letters, a 26-slot count array is the natural tool.

---

##### Approach 1: Brute Force (Sort and Compare)

**Intuition**: Sorting puts both strings' characters into a canonical order. Anagrams become identical after sorting.

**Algorithm**:
1. If lengths differ, return `false`.
2. Convert both strings to char arrays and sort them.
3. Return `Arrays.equals` on the two sorted arrays.

```java
import java.util.Arrays;

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        char[] a = s.toCharArray();
        char[] b = t.toCharArray();
        Arrays.sort(a);
        Arrays.sort(b);
        return Arrays.equals(a, b);
    }
}
```
- **Time Complexity**: $O(n \log n)$
- **Space Complexity**: $O(n)$ for the char arrays

---

##### Approach 2: Better (HashMap of Counts)

**Intuition**: Count each character in `s`, then subtract for each character in `t`. Anagrams end with all counts at zero. This works for any character set, not just lowercase letters.

**Algorithm**:
1. If lengths differ, return `false`.
2. For each character in `s`, increment its count in a `HashMap`.
3. For each character in `t`, decrement its count. If the count is missing or would go below zero, return `false`.
4. Return `true`.

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        Map<Character, Integer> counts = new HashMap<>();
        for (char c : s.toCharArray()) {
            counts.merge(c, 1, Integer::sum);
        }
        for (char c : t.toCharArray()) {
            int remaining = counts.getOrDefault(c, 0) - 1;
            if (remaining < 0) {
                return false;
            }
            counts.put(c, remaining);
        }
        return true;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(k)$, where $k$ is the number of distinct characters

---

##### Approach 3: Optimised (Fixed Array, Two Passes)

**Intuition**: With only 26 lowercase letters, a plain `int[26]` replaces the hash map. Array indexing is faster than hashing and avoids boxing.

**Algorithm**:
1. If lengths differ, return `false`.
2. Count each letter of `s` into `counts[c - 'a']`.
3. Subtract each letter of `t`. If any count goes negative, return `false`.
4. Return `true`.

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        int[] counts = new int[26];
        for (int i = 0; i < s.length(); i++) {
            counts[s.charAt(i) - 'a']++;
        }
        for (int i = 0; i < t.length(); i++) {
            if (--counts[t.charAt(i) - 'a'] < 0) {
                return false;
            }
        }
        return true;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$, a fixed 26-slot array

---

##### Approach 4: Best (Single Array, Single Pass Check)

**Intuition**: Since the lengths are equal, if no count ever goes negative, every count must end at zero. So one array can be incremented for `s` and decremented for `t`, and the result is determined by whether all slots are zero at the end.

**Algorithm**:
1. If lengths differ, return `false`.
2. For each index `i`, do `counts[s[i]-'a']++` and `counts[t[i]-'a']--`.
3. Scan the 26 slots. If any is non-zero, return `false`.
4. Return `true`.

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        int[] counts = new int[26];
        for (int i = 0; i < s.length(); i++) {
            counts[s.charAt(i) - 'a']++;
            counts[t.charAt(i) - 'a']--;
        }
        for (int c : counts) {
            if (c != 0) {
                return false;
            }
        }
        return true;
    }
}
```
- **Time Complexity**: $O(n + 26) = O(n)$
- **Space Complexity**: $O(1)$

### 1.3 Two Sum
- **Difficulty**: Easy
- **LeetCode**: [1. Two Sum](https://leetcode.com/problems/two-sum/)
- **NeetCode**: [Two Sum](https://neetcode.io/problems/two-sum)
- **Data Structures**: Array, Hash Table
- **Patterns**: Hash Map Complement, Sort + Two Pointers (alternate)

#### Problem Description
Given an array of integers `nums` and an integer `target`, return the indices of the two numbers such that they add up to `target`.

You may assume that each input has **exactly one solution**, and you **may not use the same element twice**. The answer can be returned in any order.

#### Examples

**Example 1**
- **Input**: `nums = [2,7,11,15]`, `target = 9`
- **Output**: `[0,1]`
- **Explanation**: `nums[0] + nums[1] = 2 + 7 = 9`

**Example 2**
- **Input**: `nums = [3,2,4]`, `target = 6`
- **Output**: `[1,2]`
- **Explanation**: `nums[1] + nums[2] = 2 + 4 = 6`

#### Constraints
- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- Exactly one valid answer exists.

#### Intuition
For every element `x` you visit, the only partner that completes the pair is `target - x`. The question becomes: *have I already seen `target - x` earlier in the array?* A hash map answers that membership question in O(1), which turns a search problem over pairs into a single lookup per element. Every approach below is a different way of answering that question, or of avoiding it.

---

##### Approach 1: Brute Force (Nested Loops)

**Intuition**: Check every possible pair. There are n(n-1)/2 pairs, so this is exhaustive and needs no extra memory.

**Algorithm**:
1. For each index `i` from `0` to `n-1`.
2. For each index `j` from `i+1` to `n-1`.
3. If `nums[i] + nums[j] == target`, return `{i, j}`.
4. If no pair matches, return an empty array (unreachable under the problem guarantee).

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] + nums[j] == target) {
                    return new int[]{i, j};
                }
            }
        }
        return new int[]{};
    }
}
```
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$

---

##### Approach 2: Better (Sort + Two Pointers)

**Intuition**: On a sorted array, a pair's sum moves predictably. If the sum is too small, move the left pointer right to increase it. If too large, move the right pointer left to decrease it. Sorting destroys original positions, so we sort an array of **indices** by their values and report the original indices at the end.

**Algorithm**:
1. Build `idx = [0, 1, ..., n-1]` and sort `idx` by `nums[idx[k]]`.
2. Set `lo = 0`, `hi = n-1`.
3. While `lo < hi`:
   - `sum = nums[idx[lo]] + nums[idx[hi]]`.
   - If `sum == target`, return `{idx[lo], idx[hi]}`.
   - If `sum < target`, increment `lo`. Otherwise decrement `hi`.
4. Return an empty array.

```java
import java.util.Arrays;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        int n = nums.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) {
            idx[i] = i;
        }
        Arrays.sort(idx, (a, b) -> Integer.compare(nums[a], nums[b]));

        int lo = 0, hi = n - 1;
        while (lo < hi) {
            long sum = (long) nums[idx[lo]] + nums[idx[hi]];
            if (sum == target) {
                return new int[]{idx[lo], idx[hi]};
            }
            if (sum < target) {
                lo++;
            } else {
                hi--;
            }
        }
        return new int[]{};
    }
}
```
- **Time Complexity**: $O(n \log n)$ for the sort, $O(n)$ for the scan, so $O(n \log n)$ overall
- **Space Complexity**: $O(n)$ for the index array

---

##### Approach 3: Optimised (Two-Pass Hash Table)

**Intuition**: Replace the inner search with a hash lookup. First index every value, then scan again and ask whether each element's complement exists at a different index.

**Algorithm**:
1. Pass 1: insert every `nums[i] -> i` into a `HashMap`.
2. Pass 2: for each `i`, compute `complement = target - nums[i]`.
3. If the map contains `complement` and its stored index is not `i`, return `{i, map.get(complement)}`.

The `!= i` check prevents using the same element twice. It matters when `complement == nums[i]` (for example, `nums = [3,3]`, `target = 6`).

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> indexOf = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            indexOf.put(nums[i], i);
        }
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            Integer j = indexOf.get(complement);
            if (j != null && j != i) {
                return new int[]{i, j};
            }
        }
        return new int[]{};
    }
}
```
- **Time Complexity**: $O(n)$ (two linear passes, O(1) average lookups)
- **Space Complexity**: $O(n)$ for the hash map

---

##### Approach 4: Best (One-Pass Hash Table, NeetCode Solution)

**Intuition**: The two-pass version is unnecessary. When processing index `i`, every earlier element is already in the map. So either the complement is among those earlier elements (we have our pair), or we store the current element for future lookups. Checking before inserting also guarantees the same element is never paired with itself.

**Algorithm**:
1. Create an empty map `seen: value -> index`.
2. For each `i` from `0` to `n-1`:
   - `complement = target - nums[i]`.
   - If `seen` contains `complement`, return `{seen.get(complement), i}`.
   - Otherwise, store `seen.put(nums[i], i)`.
3. Return an empty array.

Because we return on the first match, the scan often ends before reaching the end of the array.

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> seen = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (seen.containsKey(complement)) {
                return new int[]{seen.get(complement), i};
            }
            seen.put(nums[i], i);
        }
        return new int[]{};
    }
}
```
- **Time Complexity**: $O(n)$ (single pass, O(1) average per hash operation)
- **Space Complexity**: $O(n)$ worst case for the hash map

### 1.4 Group Anagrams
- **Difficulty**: Medium
- **LeetCode**: [49. Group Anagrams](https://leetcode.com/problems/group-anagrams/)
- **NeetCode**: [Group Anagrams](https://neetcode.io/problems/anagram-groups)
- **Data Structures**: Array, String, Hash Table
- **Patterns**: Canonical Key Hashing

#### Problem Description
Given an array of strings `strs`, group the anagrams together. You can return the answer in any order.

#### Examples

**Example 1**
- **Input**: `strs = ["eat","tea","tan","ate","nat","bat"]`
- **Output**: `[["bat"],["nat","tan"],["ate","eat","tea"]]`
- **Explanation**: `"eat"`, `"tea"`, `"ate"` share the same letters, as do `"tan"` and `"nat"`. `"bat"` has none in common with the others.

**Example 2**
- **Input**: `strs = [""]`
- **Output**: `[[""]]`
- **Explanation**: A single empty string forms its own group.

#### Constraints
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` consists of lowercase English letters.

#### Intuition
Anagrams share a signature: their sorted form, or their letter-count profile. If every word is mapped to its signature, words with the same signature are exactly the anagram groups. The problem reduces to "group by a key," which a hash map handles directly.

---

##### Approach 1: Brute Force (Pairwise Comparison)

**Intuition**: For each word, compare it against every existing group's first word using sorted equality. Add it to the first matching group, or start a new one.

**Algorithm**:
1. Keep a list of groups.
2. For each string `s`, sort its characters into `key`.
3. For each existing group, sort its first string and compare with `key`. If equal, add `s` to that group.
4. If no group matches, create a new group with `s`.

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> groups = new ArrayList<>();
        for (String s : strs) {
            String key = sorted(s);
            boolean placed = false;
            for (List<String> group : groups) {
                if (sorted(group.get(0)).equals(key)) {
                    group.add(s);
                    placed = true;
                    break;
                }
            }
            if (!placed) {
                List<String> fresh = new ArrayList<>();
                fresh.add(s);
                groups.add(fresh);
            }
        }
        return groups;
    }

    private String sorted(String s) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        return new String(chars);
    }
}
```
- **Time Complexity**: $O(n^2 \cdot k \log k)$, where $n$ is the number of strings and $k$ the max length
- **Space Complexity**: $O(n \cdot k)$

---

##### Approach 2: Better (Sorted String as Hash Key)

**Intuition**: Sorting each word gives a canonical key. Anagrams collide on that key, so a `HashMap` collects each group in one bucket.

**Algorithm**:
1. For each string, compute `key = sorted(s)`.
2. `map.computeIfAbsent(key, ...)` and add `s` to the list.
3. Return the map's values.

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            map.computeIfAbsent(new String(chars), k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```
- **Time Complexity**: $O(n \cdot k \log k)$
- **Space Complexity**: $O(n \cdot k)$

---

##### Approach 3: Optimised / Best (Character Count as Hash Key)

**Intuition**: Sorting costs $O(k \log k)$ per word, but counting letters costs $O(k)$. A 26-slot count vector identifies the anagram class just as well, so encode it as a string key such as `"a1b0c0...t1..."`. The key does not depend on letter order, so anagrams still collide.

**Algorithm**:
1. For each string, build `int[26] count` by incrementing `count[c - 'a']`.
2. Build a key by appending each count with a separator, for example `"#1#0#0..."`.
3. Group by key with a `HashMap`.
4. Return the map's values.

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            int[] count = new int[26];
            for (char c : s.toCharArray()) {
                count[c - 'a']++;
            }
            StringBuilder key = new StringBuilder();
            for (int c : count) {
                key.append('#').append(c);
            }
            map.computeIfAbsent(key.toString(), k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```
- **Time Complexity**: $O(n \cdot (k + 26))$, which is $O(n \cdot k)$ for long strings
- **Space Complexity**: $O(n \cdot k)$

### 1.5 Top K Frequent Elements
- **Difficulty**: Medium
- **LeetCode**: [347. Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/)
- **NeetCode**: [Top K Elements in List](https://neetcode.io/problems/top-k-elements-in-list)
- **Data Structures**: Array, Hash Table, Heap, Bucket
- **Patterns**: Frequency Map, Min-Heap of Size K, Bucket Sort

#### Problem Description
Given an integer array `nums` and an integer `k`, return the `k` most frequent elements. You may return the answer in any order.

#### Examples

**Example 1**
- **Input**: `nums = [1,1,1,2,2,3]`, `k = 2`
- **Output**: `[1,2]`
- **Explanation**: `1` appears 3 times and `2` appears 2 times.

**Example 2**
- **Input**: `nums = [1]`, `k = 1`
- **Output**: `[1]`
- **Explanation**: The only element is also the most frequent.

#### Constraints
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= number of distinct elements in nums`
- The answer is unique.

#### Intuition
Two steps: count frequencies, then select the top `k`. Selecting by sorting costs $O(d \log d)$ for $d$ distinct values. A min-heap of size `k` keeps only the best `k` seen so far. Since a frequency is never larger than `n`, bucket sort can index frequencies directly and avoid comparisons entirely.

---

##### Approach 1: Brute Force (Count, then Sort)

**Intuition**: Count every value, sort the entries by frequency descending, and take the first `k`.

**Algorithm**:
1. Build `freq: value -> count`.
2. Copy entries into a list and sort by count, descending.
3. Take the first `k` keys.

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            freq.merge(x, 1, Integer::sum);
        }
        List<Map.Entry<Integer, Integer>> entries = new ArrayList<>(freq.entrySet());
        entries.sort((a, b) -> b.getValue() - a.getValue());
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = entries.get(i).getKey();
        }
        return result;
    }
}
```
- **Time Complexity**: $O(n + d \log d)$, where $d$ is the number of distinct values
- **Space Complexity**: $O(d)$

---

##### Approach 2: Better (Min-Heap of Size K)

**Intuition**: Keep a min-heap of the `k` most frequent entries seen so far. The root is the least frequent of those `k`. Any new entry more frequent than the root replaces it. The heap never grows beyond `k`.

**Algorithm**:
1. Count frequencies.
2. Push each entry into a min-heap ordered by count.
3. If the heap size exceeds `k`, poll the smallest.
4. The heap now holds the top `k`. Extract their keys.

```java
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            freq.merge(x, 1, Integer::sum);
        }
        PriorityQueue<Map.Entry<Integer, Integer>> minHeap =
            new PriorityQueue<>((a, b) -> a.getValue() - b.getValue());
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            minHeap.offer(e);
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = minHeap.poll().getKey();
        }
        return result;
    }
}
```
- **Time Complexity**: $O(n + d \log k)$
- **Space Complexity**: $O(d + k)$

---

##### Approach 3: Optimised / Best (Bucket Sort by Frequency)

**Intuition**: A value's frequency is between 1 and `n`. Create `n+1` buckets, where bucket `f` holds all values with frequency `f`. Walk the buckets from highest frequency downward and collect until you have `k` values. No comparisons are needed.

**Algorithm**:
1. Count frequencies.
2. Create `buckets[0..n]`, each an empty list.
3. For each `(value, f)`, add `value` to `buckets[f]`.
4. Iterate `f` from `n` down to `1`, appending values from each bucket until the result has `k` items.

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            freq.merge(x, 1, Integer::sum);
        }
        int n = nums.length;
        List<List<Integer>> buckets = new ArrayList<>();
        for (int i = 0; i <= n; i++) {
            buckets.add(new ArrayList<>());
        }
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            buckets.get(e.getValue()).add(e.getKey());
        }
        int[] result = new int[k];
        int idx = 0;
        for (int f = n; f >= 1 && idx < k; f--) {
            for (int value : buckets.get(f)) {
                result[idx++] = value;
                if (idx == k) {
                    break;
                }
            }
        }
        return result;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(n)$

### 1.6 Product of Array Except Self
- **Difficulty**: Medium
- **LeetCode**: [238. Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/)
- **NeetCode**: [Product of Array Except Self](https://neetcode.io/problems/products-of-array-except-self)
- **Data Structures**: Array
- **Patterns**: Prefix and Suffix Products

#### Problem Description
Given an integer array `nums`, return an array `answer` such that `answer[i]` equals the product of all elements of `nums` except `nums[i]`.

You must write an algorithm that runs in $O(n)$ time and does **not** use the division operator.

#### Examples

**Example 1**
- **Input**: `nums = [1,2,3,4]`
- **Output**: `[24,12,8,6]`
- **Explanation**: `answer[0] = 2*3*4 = 24`, `answer[1] = 1*3*4 = 12`, and so on.

**Example 2**
- **Input**: `nums = [-1,1,0,-3,3]`
- **Output**: `[0,0,9,0,0]`
- **Explanation**: Any product that includes the `0` at index 2 is zero, except at index 2 itself, where the product is `-1*1*-3*3 = 9`.

#### Constraints
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- The product of any prefix or suffix fits in a 32-bit integer.

#### Intuition
`answer[i]` is the product of everything to its left times everything to its right. Precompute both sides. Division would be simplest but breaks on zeros and is disallowed, so separate the left and right contributions.

---

##### Approach 1: Brute Force (Product per Index)

**Intuition**: For each index, multiply every other element.

**Algorithm**:
1. For each `i`, set `prod = 1`.
2. For each `j != i`, multiply `prod` by `nums[j]`.
3. Store `prod` in `answer[i]`.

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        for (int i = 0; i < n; i++) {
            int prod = 1;
            for (int j = 0; j < n; j++) {
                if (j != i) {
                    prod *= nums[j];
                }
            }
            answer[i] = prod;
        }
        return answer;
    }
}
```
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$ extra (excluding output)

---

##### Approach 2: Better (Prefix and Suffix Arrays)

**Intuition**: `answer[i] = prefix[i] * suffix[i]`, where `prefix[i]` is the product of `nums[0..i-1]` and `suffix[i]` is the product of `nums[i+1..n-1]`. Build both arrays with one pass each.

**Algorithm**:
1. `prefix[0] = 1`, and `prefix[i] = prefix[i-1] * nums[i-1]`.
2. `suffix[n-1] = 1`, and `suffix[i] = suffix[i+1] * nums[i+1]`.
3. `answer[i] = prefix[i] * suffix[i]`.

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] prefix = new int[n];
        int[] suffix = new int[n];
        prefix[0] = 1;
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] * nums[i - 1];
        }
        suffix[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] * nums[i + 1];
        }
        int[] answer = new int[n];
        for (int i = 0; i < n; i++) {
            answer[i] = prefix[i] * suffix[i];
        }
        return answer;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(n)$ for the two auxiliary arrays

---

##### Approach 3: Optimised / Best (In-Place Prefix, Running Suffix)

**Intuition**: The output array can hold the prefix products. Then a single right-to-left pass with one running variable multiplies in the suffix product, so the separate suffix array is unnecessary.

**Algorithm**:
1. Pass left to right: `answer[i] = product of nums[0..i-1]`, tracked with a running `left`.
2. Pass right to left with a running `right = 1`: `answer[i] *= right`, then `right *= nums[i]`.

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        int left = 1;
        for (int i = 0; i < n; i++) {
            answer[i] = left;
            left *= nums[i];
        }
        int right = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= right;
            right *= nums[i];
        }
        return answer;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$ extra (excluding output)

### 1.7 Valid Sudoku
- **Difficulty**: Medium
- **LeetCode**: [36. Valid Sudoku](https://leetcode.com/problems/valid-sudoku/)
- **NeetCode**: [Valid Sudoku](https://neetcode.io/problems/valid-sudoku)
- **Data Structures**: Array, Hash Set, Bit Manipulation
- **Patterns**: Row/Column/Box Constraint Tracking

#### Problem Description
Determine if a `9 x 9` Sudoku board is valid. Only the **filled** cells need to be validated, according to the following rules:
1. Each row must contain the digits `1-9` without repetition.
2. Each column must contain the digits `1-9` without repetition.
3. Each of the nine `3 x 3` sub-boxes must contain the digits `1-9` without repetition.

The board is not required to be solvable. Empty cells are represented by `'.'`.

#### Examples

**Example 1**
- **Input**: `board` with rows `["5","3",".",".","7",".",".",".","."]`, `["6",".",".","1","9","5",".",".","."]`, and so on, as in the standard LeetCode example.
- **Output**: `true`
- **Explanation**: No row, column, or box has a repeated digit.

**Example 2**
- **Input**: Same as Example 1, but `board[0][0] = "8"`.
- **Output**: `false`
- **Explanation**: The digit `8` now appears twice in the top-left box.

#### Constraints
- `board.length == 9`, `board[i].length == 9`
- `board[i][j]` is a digit `'1'`-`'9'` or `'.'`.

#### Intuition
Each cell belongs to exactly three groups: its row, its column, and its box. The board is valid if no group has a repeated digit. So for every filled cell, check whether its digit has already appeared in any of those three groups. Each group has 9 cells, so the work is bounded and constant.

Box index for cell `(r, c)`: `(r / 3) * 3 + (c / 3)`, which runs from `0` to `8`.

---

##### Approach 1: Brute Force (Scan the Three Groups for Each Cell)

**Intuition**: For each filled cell, scan its row, column, and box for another cell with the same digit.

**Algorithm**:
1. For each cell `(r, c)` with a digit `d`.
2. Scan the other cells in row `r`, column `c`, and the box containing `(r, c)`. If any holds `d`, return `false`.
3. Return `true` after all cells pass.

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                char d = board[r][c];
                if (d == '.') continue;
                for (int k = 0; k < 9; k++) {
                    if (k != c && board[r][k] == d) return false;
                    if (k != r && board[k][c] == d) return false;
                }
                int br = (r / 3) * 3, bc = (c / 3) * 3;
                for (int i = br; i < br + 3; i++) {
                    for (int j = bc; j < bc + 3; j++) {
                        if ((i != r || j != c) && board[i][j] == d) return false;
                    }
                }
            }
        }
        return true;
    }
}
```
- **Time Complexity**: $O(81 \cdot 27) = O(1)$ for the fixed 9x9 board
- **Space Complexity**: $O(1)$

---

##### Approach 2: Better (HashSet of Labelled Strings)

**Intuition**: Record each placement as a string such as `"5 in row 0"`, `"5 in col 0"`, and `"5 in box 0"`. Any repeated string means a conflict. One set replaces all the scanning.

**Algorithm**:
1. For each filled cell `(r, c)` with digit `d`, build three keys: row, column, and box.
2. Try `seen.add(key)` for each. If it returns `false`, return `false`.
3. Return `true`.

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isValidSudoku(char[][] board) {
        Set<String> seen = new HashSet<>();
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                char d = board[r][c];
                if (d == '.') continue;
                int box = (r / 3) * 3 + (c / 3);
                if (!seen.add(d + " in row " + r)) return false;
                if (!seen.add(d + " in col " + c)) return false;
                if (!seen.add(d + " in box " + box)) return false;
            }
        }
        return true;
    }
}
```
- **Time Complexity**: $O(1)$ for the fixed board (at most 243 insertions)
- **Space Complexity**: $O(1)$ bounded by 243 entries

---

##### Approach 3: Optimised (Boolean Arrays)

**Intuition**: Replace string keys with three `boolean[9][9]` tables indexed by `[group][digit]`. Array access is cheaper than string building and hashing.

**Algorithm**:
1. For each filled cell with digit `d` (converted to index `d - '1'`):
2. If `rows[r][d]`, `cols[c][d]`, or `boxes[box][d]` is already set, return `false`.
3. Otherwise, set all three to `true`.

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        boolean[][] rows = new boolean[9][9];
        boolean[][] cols = new boolean[9][9];
        boolean[][] boxes = new boolean[9][9];
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                char ch = board[r][c];
                if (ch == '.') continue;
                int d = ch - '1';
                int box = (r / 3) * 3 + (c / 3);
                if (rows[r][d] || cols[c][d] || boxes[box][d]) {
                    return false;
                }
                rows[r][d] = cols[c][d] = boxes[box][d] = true;
            }
        }
        return true;
    }
}
```
- **Time Complexity**: $O(1)$ for the fixed board
- **Space Complexity**: $O(1)$, 243 booleans

---

##### Approach 4: Best (Bitmasks)

**Intuition**: Each group needs only 9 bits, one per digit. Store each row, column, and box as a single `int` bitmask. Setting bit `d` marks digit `d` as used, and `(mask >> d) & 1` checks it. This uses the least memory and fewest memory accesses.

**Algorithm**:
1. Keep `int[] rows = new int[9]`, `cols`, and `boxes`.
2. For digit `d` (as `0..8`), let `bit = 1 << d`.
3. If `rows[r] & bit`, `cols[c] & bit`, or `boxes[box] & bit` is set, return `false`.
4. Otherwise OR the bit into all three masks.

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        int[] rows = new int[9];
        int[] cols = new int[9];
        int[] boxes = new int[9];
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                char ch = board[r][c];
                if (ch == '.') continue;
                int bit = 1 << (ch - '1');
                int box = (r / 3) * 3 + (c / 3);
                if ((rows[r] & bit) != 0 || (cols[c] & bit) != 0 || (boxes[box] & bit) != 0) {
                    return false;
                }
                rows[r] |= bit;
                cols[c] |= bit;
                boxes[box] |= bit;
            }
        }
        return true;
    }
}
```
- **Time Complexity**: $O(1)$ for the fixed board
- **Space Complexity**: $O(1)$, 27 integers

### 1.8 Longest Consecutive Sequence
- **Difficulty**: Medium
- **LeetCode**: [128. Longest Consecutive Sequence](https://leetcode.com/problems/longest-consecutive-sequence/)
- **NeetCode**: [Longest Consecutive Sequence](https://neetcode.io/problems/longest-consecutive-sequence)
- **Data Structures**: Array, Hash Set
- **Patterns**: Sequence Start Detection

#### Problem Description
Given an unsorted array of integers `nums`, return the length of the longest consecutive elements sequence.

You must write an algorithm that runs in $O(n)$ time.

#### Examples

**Example 1**
- **Input**: `nums = [100,4,200,1,3,2]`
- **Output**: `4`
- **Explanation**: The longest consecutive run is `[1, 2, 3, 4]`.

**Example 2**
- **Input**: `nums = [0,3,7,2,5,8,4,6,0,1]`
- **Output**: `9`
- **Explanation**: The run `[0, 1, 2, 3, 4, 5, 6, 7, 8]` has length 9.

#### Constraints
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

#### Intuition
A consecutive run has exactly one starting element, the one whose predecessor `x - 1` is absent. If you start counting only from those starts, each element is visited a bounded number of times. Sorting also works, but costs $O(n \log n)$.

---

##### Approach 1: Brute Force (Count Upward for Every Number)

**Intuition**: For each number, keep looking for `x+1`, `x+2`, and so on with a linear search. Track the longest run.

**Algorithm**:
1. For each `x` in `nums`, set `len = 1` and `cur = x`.
2. While `cur + 1` exists in `nums` (linear scan), increment `cur` and `len`.
3. Track the maximum `len`.

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        int best = 0;
        for (int x : nums) {
            int cur = x, len = 1;
            while (contains(nums, cur + 1)) {
                cur++;
                len++;
            }
            best = Math.max(best, len);
        }
        return best;
    }

    private boolean contains(int[] nums, int target) {
        for (int v : nums) {
            if (v == target) return true;
        }
        return false;
    }
}
```
- **Time Complexity**: $O(n^3)$ worst case, since each `contains` is $O(n)$
- **Space Complexity**: $O(1)$

---

##### Approach 2: Better (Sort, then Scan)

**Intuition**: After sorting, a consecutive run is a block of adjacent elements that differ by exactly 1. Duplicates must be skipped. Scan once and track the current run length.

**Algorithm**:
1. If empty, return `0`.
2. Sort `nums`.
3. Scan `i` from `1`. If `nums[i] == nums[i-1]`, skip. If `nums[i] == nums[i-1] + 1`, extend the run. Otherwise, reset the run to `1`.
4. Track the maximum run length.

```java
import java.util.Arrays;

class Solution {
    public int longestConsecutive(int[] nums) {
        if (nums.length == 0) return 0;
        Arrays.sort(nums);
        int best = 1, cur = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] == nums[i - 1]) continue;
            if (nums[i] == nums[i - 1] + 1) {
                cur++;
            } else {
                cur = 1;
            }
            best = Math.max(best, cur);
        }
        return best;
    }
}
```
- **Time Complexity**: $O(n \log n)$
- **Space Complexity**: $O(1)$ extra (plus sort stack)

---

##### Approach 3: Optimised / Best (HashSet, Start Only at Sequence Beginnings)

**Intuition**: Put all numbers in a set. Start counting only from `x` where `x - 1` is absent, which guarantees each run is walked exactly once. Every element is touched at most twice (once as a candidate start, once inside a run), so the total work is linear.

**Algorithm**:
1. Insert all numbers into `set`.
2. For each `x` in `set`: if `set` contains `x - 1`, skip it.
3. Otherwise, count `len` by checking `x+1`, `x+2`, ... in the set.
4. Track the maximum length.

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) {
            set.add(x);
        }
        int best = 0;
        for (int x : set) {
            if (set.contains(x - 1)) continue;
            int len = 1;
            while (set.contains(x + len)) {
                len++;
            }
            best = Math.max(best, len);
        }
        return best;
    }
}
```
- **Time Complexity**: $O(n)$ average
- **Space Complexity**: $O(n)$

### 1.9 Encode and Decode Strings
- **Difficulty**: Medium
- **LeetCode**: [271. Encode and Decode Strings (Premium)](https://leetcode.com/problems/encode-and-decode-strings/)
- **NeetCode**: [Encode and Decode Strings](https://neetcode.io/problems/string-encode-and-decode)
- **Data Structures**: Array, String
- **Patterns**: Escaping, Length-Prefix Encoding

#### Problem Description
Design an algorithm to encode a list of strings into a single string, and decode that string back into the original list. The strings may contain any valid ASCII characters, including the delimiter you choose. The encoding must be reversible.

Implement:
- `String encode(List<String> strs)`
- `List<String> decode(String str)`

#### Examples

**Example 1**
- **Input**: `strs = ["neet","code","love","you"]`
- **Output**: `decode(encode(strs)) == ["neet","code","love","you"]`
- **Explanation**: Round-trip must return the exact original list.

**Example 2**
- **Input**: `strs = ["we","say",":","yes"]`
- **Output**: `decode(encode(strs)) == ["we","say",":","yes"]`
- **Explanation**: A string containing `:` must not be confused with the separator.

#### Constraints
- `0 <= strs.length < 100`
- `0 <= strs[i].length < 200`
- `strs[i]` contains any ASCII character.

#### Intuition
A delimiter alone fails the moment the data contains the delimiter. Two robust options: escape the delimiter in the data, or prefix each string with its length so the decoder never has to guess where a string ends.

---

##### Approach 1: Brute Force (Delimiter with Escaping)

**Intuition**: Use `,` as the separator. Escape any `,` or `\` inside a string with a preceding `\`. The decoder reads characters, honours escapes, and splits on unescaped commas.

**Algorithm**:
1. Encode: for each string, write each character, prefixing `\` when the character is `,` or `\`. Then append an unescaped `,`.
2. Decode: walk the string. On `\`, take the next character literally. On an unescaped `,`, finish the current item. Otherwise, append the character.

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String encode(List<String> strs) {
        StringBuilder sb = new StringBuilder();
        for (String s : strs) {
            for (char c : s.toCharArray()) {
                if (c == ',' || c == '\\') sb.append('\\');
                sb.append(c);
            }
            sb.append(',');
        }
        return sb.toString();
    }

    public List<String> decode(String str) {
        List<String> result = new ArrayList<>();
        StringBuilder cur = new StringBuilder();
        for (int i = 0; i < str.length(); i++) {
            char c = str.charAt(i);
            if (c == '\\') {
                cur.append(str.charAt(++i));
            } else if (c == ',') {
                result.add(cur.toString());
                cur.setLength(0);
            } else {
                cur.append(c);
            }
        }
        return result;
    }
}
```
- **Time Complexity**: $O(T)$ for total length $T$ of all strings
- **Space Complexity**: $O(T)$

---

##### Approach 2: Optimised / Best (Length-Prefix Encoding, NeetCode Solution)

**Intuition**: Write each string as `length#content`. The decoder reads digits up to `#`, knows exactly how many characters follow, and jumps there. It never inspects the content, so any character, including `#` and digits, is safe.

**Algorithm**:
1. Encode: for each `s`, append `s.length()`, then `#`, then `s`.
2. Decode: keep index `i`. Find the next `#` at `j`. Parse `len = str[i..j)`. Take `str[j+1 .. j+1+len)`. Set `i = j + 1 + len`.
3. Repeat until the end of the string.

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String encode(List<String> strs) {
        StringBuilder sb = new StringBuilder();
        for (String s : strs) {
            sb.append(s.length()).append('#').append(s);
        }
        return sb.toString();
    }

    public List<String> decode(String str) {
        List<String> result = new ArrayList<>();
        int i = 0;
        while (i < str.length()) {
            int j = str.indexOf('#', i);
            int len = Integer.parseInt(str.substring(i, j));
            result.add(str.substring(j + 1, j + 1 + len));
            i = j + 1 + len;
        }
        return result;
    }
}
```
- **Time Complexity**: $O(T)$ for encode and decode
- **Space Complexity**: $O(T)$

### 2.1 Valid Palindrome
- **Difficulty**: Easy
- **LeetCode**: [125. Valid Palindrome](https://leetcode.com/problems/valid-palindrome/)
- **NeetCode**: [Valid Palindrome](https://neetcode.io/problems/is-palindrome)
- **Data Structures**: String, Two Pointers
- **Patterns**: Left-Right Pointers

#### Problem Description
A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers. Given a string `s`, return `true` if it is a palindrome, or `false` otherwise.

#### Inputs & Outputs
- **Input**: `s = "A man, a plan, a canal: Panama"` -> **Output**: `true`
- **Input**: `s = "race a car"` -> **Output**: `false`
- **Constraints**: `1 <= s.length <= 2 * 10^5`, printable ASCII characters.

#### Solutions

##### Approach 1: Brute Force (Filter and Reverse)
Filter out non-alphanumeric characters, convert to lowercase, and reverse the string to check equality.
```java
class Solution {
    public boolean isPalindrome(String s) {
        StringBuilder filtered = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                filtered.append(Character.toLowerCase(c));
            }
        }
        return filtered.toString().equals(filtered.reverse().toString());
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(n)$

##### Approach 2: Optimised / Best (Two Pointers In-Place)
Use `left` and `right` pointers meeting in the middle, skipping non-alphanumeric characters without extra memory.
```java
class Solution {
    public boolean isPalindrome(String s) {
        int left = 0, right = s.length() - 1;
        while (left < right) {
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }
            if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$

### 2.2 Two Sum II - Input Array Is Sorted
- **Difficulty**: Medium
- **LeetCode**: [167. Two Sum II - Input Array Is Sorted](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)
- **NeetCode**: [Two Integer Sum II](https://neetcode.io/problems/two-integer-sum-ii)
- **Data Structures**: Array, Two Pointers
- **Patterns**: Two Pointers on Sorted Array

#### Problem Description
Given a 1-indexed array of integers `numbers` that is already sorted in non-decreasing order, find two numbers such that they add up to a specific `target` number. Return the indices of the two numbers, `index1` and `index2`, added by one as an integer array `[index1, index2]` of length 2.

#### Inputs & Outputs
- **Input**: `numbers = [2,7,11,15]`, `target = 9` -> **Output**: `[1,2]`
- **Constraints**: `2 <= numbers.length <= 3 * 10^4`, `-1000 <= numbers[i] <= 1000`, sorted.

#### Solutions

##### Approach 1: Brute Force (Nested Loops)
Test every pair with nested loops.
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$

##### Approach 2: Better (Binary Search)
For each element `numbers[i]`, binary search for `target - numbers[i]` in the subarray `numbers[i+1...n-1]`.
```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        for (int i = 0; i < numbers.length; i++) {
            int complement = target - numbers[i];
            int low = i + 1, high = numbers.length - 1;
            while (low <= high) {
                int mid = low + (high - low) / 2;
                if (numbers[mid] == complement) return new int[]{i + 1, mid + 1};
                else if (numbers[mid] < complement) low = mid + 1;
                else high = mid - 1;
            }
        }
        return new int[]{-1, -1};
    }
}
```
- **Time Complexity**: $O(n \log n)$
- **Space Complexity**: $O(1)$

##### Approach 3: Optimised / Best (Two Pointers)
Initialize `left = 0`, `right = numbers.length - 1`. If sum is too small, increment `left`; if too large, decrement `right`.
```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0, right = numbers.length - 1;
        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                return new int[]{left + 1, right + 1};
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
        return new int[]{-1, -1};
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$

### 2.3 3Sum
- **Difficulty**: Medium
- **LeetCode**: [15. 3Sum](https://leetcode.com/problems/3sum/)
- **NeetCode**: [3Sum](https://neetcode.io/problems/three-integer-sum)
- **Data Structures**: Array, Two Pointers
- **Patterns**: Sort + Two Pointers

#### Problem Description
Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`. The solution set must not contain duplicate triplets.

#### Inputs & Outputs
- **Input**: `nums = [-1,0,1,2,-1,-4]` -> **Output**: `[[-1,-1,2],[-1,0,1]]`
- **Constraints**: `3 <= nums.length <= 3000`, `-10^5 <= nums[i] <= 10^5`

#### Solutions

##### Approach 1: Brute Force (Three Nested Loops + Set)
Iterate through all triples $i < j < k$, sort each valid triple and store in a `Set<List<Integer>>`.
- **Time Complexity**: $O(n^3)$
- **Space Complexity**: $O(n)$

##### Approach 2: Better (Sort + Two Pointers with Deduplication)
Sort the array. For each index `i`, run two pointers `left = i + 1`, `right = n - 1`. Skip duplicate values for `i`, `left`, and `right`.
```java
import java.util.*;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums);
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) break; // impossible to sum to 0
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int left = i + 1, right = nums.length - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum == 0) {
                    res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    left++;
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        return res;
    }
}
```
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$ auxiliary (ignoring output)

### 2.4 Container With Most Water
- **Difficulty**: Medium

#### Problem Description
Given `n` non-negative integers `height` where each represents a point at coordinate `(i, height[i])`. Find two lines that together with the x-axis form a container, such that the container contains the most water. Return the maximum amount of water a container can store.

#### Inputs & Outputs
- **Input**: `height = [1,8,6,2,5,4,8,3,7]` -> **Output**: `49`
- **Constraints**: `n == height.length`, `2 <= n <= 10^5`, `0 <= height[i] <= 10^4`

#### Solutions

##### Approach 1: Brute Force (All Pairs)
Calculate area for all possible pairs $(i, j)$ and track the maximum.
```java
class Solution {
    public int maxArea(int[] height) {
        int max = 0;
        for (int i = 0; i < height.length; i++) {
            for (int j = i + 1; j < height.length; j++) {
                int area = Math.min(height[i], height[j]) * (j - i);
                max = Math.max(max, area);
            }
        }
        return max;
    }
}
```
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$

##### Approach 2: Optimised / Best (Two Pointers Greedy)
Place pointers at ends `left = 0`, `right = n - 1`. Area is constrained by the shorter line, so move the pointer pointing to the shorter line inward.
```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0, right = height.length - 1;
        int maxArea = 0;
        while (left < right) {
            int h = Math.min(height[left], height[right]);
            maxArea = Math.max(maxArea, h * (right - left));
            while (left < right && height[left] <= h) left++;
            while (left < right && height[right] <= h) right--;
        }
        return maxArea;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$

### 2.5 Trapping Rain Water
- **Difficulty**: Hard
- **LeetCode**: [42. Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/)
- **NeetCode**: [Trapping Rain Water](https://neetcode.io/problems/trapping-rain-water)
- **Data Structures**: Array, Two Pointers, Stack
- **Patterns**: Two Pointers / Monotonic Stack / Prefix-Suffix

#### Problem Description
Given `n` non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

#### Inputs & Outputs
- **Input**: `height = [0,1,0,2,1,0,1,3,2,1,2,1]` -> **Output**: `6`
- **Constraints**: `n == height.length`, `1 <= n <= 2 * 10^4`, `0 <= height[i] <= 10^5`

#### Solutions

##### Approach 1: Brute Force
For each bar, find `max_left` and `max_right`. Water trapped above bar $i$ is $\max(0, \min(\text{max\_left}, \text{max\_right}) - \text{height}[i])$.
- **Time Complexity**: $O(n^2)$
- **Space Complexity**: $O(1)$

##### Approach 2: Better (Dynamic Programming / Prefix-Suffix Max Arrays)
Precompute `leftMax[i]` and `rightMax[i]` in two linear passes.
```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n == 0) return 0;
        int[] leftMax = new int[n];
        int[] rightMax = new int[n];
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i + 1], height[i]);
        int trapped = 0;
        for (int i = 0; i < n; i++) {
            trapped += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        return trapped;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(n)$

##### Approach 3: Better (Monotonic Decreasing Stack)
Maintain indices of bars in a stack. When a taller bar is found, pop and calculate trapped water layer by layer.
```java
import java.util.Stack;

class Solution {
    public int trap(int[] height) {
        Stack<Integer> stack = new Stack<>();
        int trapped = 0;
        for (int i = 0; i < height.length; i++) {
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int bottom = stack.pop();
                if (stack.isEmpty()) break;
                int distance = i - stack.peek() - 1;
                int boundedHeight = Math.min(height[i], height[stack.peek()]) - height[bottom];
                trapped += distance * boundedHeight;
            }
            stack.push(i);
        }
        return trapped;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(n)$

##### Approach 4: Best (Two Pointers with Left & Right Max)
Maintain `leftMax` and `rightMax`. Advance the pointer with the smaller max, adding trapped water on the fly.
```java
class Solution {
    public int trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int trapped = 0;
        while (left < right) {
            if (height[left] < height[right]) {
                if (height[left] >= leftMax) {
                    leftMax = height[left];
                } else {
                    trapped += leftMax - height[left];
                }
                left++;
            } else {
                if (height[right] >= rightMax) {
                    rightMax = height[right];
                } else {
                    trapped += rightMax - height[right];
                }
                right--;
            }
        }
        return trapped;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$

### 3.2 Longest Substring Without Repeating Characters
- **Difficulty**: Medium
- **LeetCode**: [3. Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)
- **NeetCode**: [Longest Substring Without Duplicates](https://neetcode.io/problems/longest-substring-without-duplicates)
- **Data Structures**: String, Hash Table
- **Patterns**: Dynamic Sliding Window

#### Problem Description
Given a string `s`, find the length of the longest substring without repeating characters.

#### Inputs & Outputs
- **Input**: `s = "abcabcbb"` -> **Output**: `3` (`"abc"`)
- **Input**: `s = "bbbbb"` -> **Output**: `1` (`"b"`)
- **Constraints**: `0 <= s.length <= 5 * 10^4`, English letters, digits, symbols and spaces.

#### Solutions

##### Approach 1: Brute Force (Check All Substrings)
Generate all substrings $O(n^2)$ and check for unique characters using a Set $O(n)$.
- **Time Complexity**: $O(n^3)$
- **Space Complexity**: $O(\min(n, m))$

##### Approach 2: Better (Sliding Window with Set)
Expand `right` pointer. If character already in set, increment `left` and remove characters until duplicate is gone.
```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> set = new HashSet<>();
        int left = 0, maxLen = 0;
        for (int right = 0; right < s.length(); right++) {
            while (set.contains(s.charAt(right))) {
                set.remove(s.charAt(left));
                left++;
            }
            set.add(s.charAt(right));
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```
- **Time Complexity**: $O(2n) = O(n)$
- **Space Complexity**: $O(\min(n, m))$

##### Approach 3: Optimised / Best (Sliding Window with Last Seen Index Map / Array)
Directly jump `left` to `lastSeen[c] + 1` whenever duplicate is found, avoiding step-by-step shrink.
```java
import java.util.Arrays;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);
        int maxLen = 0, left = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            if (lastIndex[c] >= left) {
                left = lastIndex[c] + 1;
            }
            lastIndex[c] = right;
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$ (128 ASCII array)

### 3.3 Longest Repeating Character Replacement
- **Difficulty**: Medium
- **LeetCode**: [424. Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/)
- **NeetCode**: \[suspicious link removed\]
- **Data Structures**: String, Hash Table
- **Patterns**: Sliding Window with Max Frequency

#### Problem Description
You are given a string `s` and an integer `k`. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most `k` times. Return the length of the longest substring containing the same letter you can get after performing the operations.

#### Inputs & Outputs
- **Input**: `s = "ABAB"`, `k = 2` -> **Output**: `4`
- **Input**: `s = "AABABBA"`, `k = 1` -> **Output**: `4`
- **Constraints**: `1 <= s.length <= 10^5`, uppercase English letters, `0 <= k <= s.length`.

#### Solutions

##### Approach 1: Optimised / Best (Sliding Window with Max Frequency Tracking)
A window is valid if `(windowLength - maxFreq) <= k`. Expand `right`, update `maxFreq`. If invalid, shift `left` forward by 1.
```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] count = new int[26];
        int maxCount = 0;
        int left = 0, maxLength = 0;
        for (int right = 0; right < s.length(); right++) {
            count[s.charAt(right) - 'A']++;
            maxCount = Math.max(maxCount, count[s.charAt(right) - 'A']);
            while ((right - left + 1) - maxCount > k) {
                count[s.charAt(left) - 'A']--;
                left++;
            }
            maxLength = Math.max(maxLength, right - left + 1);
        }
        return maxLength;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$ (26 integers)

### 3.4 Permutation in String
- **Difficulty**: Medium
- **LeetCode**: [567. Permutation in String](https://leetcode.com/problems/permutation-in-string/)

#### Problem Description
Given two strings `s1` and `s2`, return `true` if `s2` contains a permutation of `s1`, or `false` otherwise. In other words, return `true` if one of `s1`'s permutations is the substring of `s2`.

#### Inputs & Outputs
- **Input**: `s1 = "ab"`, `s2 = "eidbaooo"` -> **Output**: `true`
- **Input**: `s1 = "ab"`, `s2 = "eidboaoo"` -> **Output**: `false`
- **Constraints**: `1 <= s1.length, s2.length <= 10^4`, lowercase English letters.

#### Solutions

##### Approach 1: Better (Fixed-Length Window with Frequency Array Comparison)
Sliding window of fixed length `s1.length()`. Compare 26-element array equality at each step.
```java
import java.util.Arrays;

class Solution {
    public boolean checkInclusion(String s1, String s2) {
        if (s1.length() > s2.length()) return false;
        int[] s1Count = new int[26];
        int[] s2Count = new int[26];
        for (int i = 0; i < s1.length(); i++) {
            s1Count[s1.charAt(i) - 'a']++;
            s2Count[s2.charAt(i) - 'a']++;
        }
        if (Arrays.equals(s1Count, s2Count)) return true;
        for (int i = s1.length(); i < s2.length(); i++) {
            s2Count[s2.charAt(i) - 'a']++;
            s2Count[s2.charAt(i - s1.length()) - 'a']--;
            if (Arrays.equals(s1Count, s2Count)) return true;
        }
        return false;
    }
}
```
- **Time Complexity**: $O(26 \cdot n) = O(n)$
- **Space Complexity**: $O(1)$

##### Approach 2: Optimised / Best (Matches Counter $O(1)$ Per Shift)
Track the number of matching character frequencies (out of 26). When `matches == 26`, return `true`.
```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        if (s1.length() > s2.length()) return false;
        int[] s1Map = new int[26];
        int[] s2Map = new int[26];
        for (int i = 0; i < s1.length(); i++) {
            s1Map[s1.charAt(i) - 'a']++;
            s2Map[s2.charAt(i) - 'a']++;
        }
        int matches = 0;
        for (int i = 0; i < 26; i++) {
            if (s1Map[i] == s2Map[i]) matches++;
        }
        for (int i = 0; i < s2.length() - s1.length(); i++) {
            if (matches == 26) return true;
            int r = s2.charAt(i + s1.length()) - 'a';
            int l = s2.charAt(i) - 'a';
            s2Map[r]++;
            if (s2Map[r] == s1Map[r]) matches++;
            else if (s2Map[r] == s1Map[r] + 1) matches--;
            s2Map[l]--;
            if (s2Map[l] == s1Map[l]) matches++;
            else if (s2Map[l] == s1Map[l] - 1) matches--;
        }
        return matches == 26;
    }
}
```
- **Time Complexity**: $O(n)$
- **Space Complexity**: $O(1)$

### 3.5 Minimum Window Substring
- **Difficulty**: Hard
- **LeetCode**: [76. Minimum Window Substring](https://leetcode.com/problems/minimum-window-substring/)
- **NeetCode**: [Minimum Window Substring](https://neetcode.io/problems/minimum-window-with-characters)
- **Data Structures**: String, Hash Table
- **Patterns**: Sliding Window with Formed Counter

#### Problem Description
Given two strings `s` and `t` of lengths `m` and `n` respectively, return the minimum window substring of `s` such that every character in `t` (including duplicates) is included in the window. If there is no such substring, return the empty string `""`.

#### Inputs & Outputs
- **Input**: `s = "ADOBECODEBANC"`, `t = "ABC"` -> **Output**: `"BANC"`
- **Constraints**: `m == s.length`, `n == t.length`, `1 <= m, n <= 10^5`.

#### Solutions

##### Approach 1: Optimised / Best (Sliding Window with Formed Counter)
Use frequency map for `t`. Expand `right` to fulfill requirement, then contract `left` while valid to minimize window.
```java
class Solution {
    public String minWindow(String s, String t) {
        if (s.length() < t.length()) return "";
        int[] target = new int[128];
        for (char c : t.toCharArray()) target[c]++;
        int required = 0;
        for (int count : target) if (count > 0) required++;
        int[] window = new int[128];
        int formed = 0;
        int left = 0, minLen = Integer.MAX_VALUE, startIdx = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            window[c]++;
            if (target[c] > 0 && window[c] == target[c]) formed++;
            while (left <= right && formed == required) {
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    startIdx = left;
                }
                char leftChar = s.charAt(left);
                window[leftChar]--;
                if (target[leftChar] > 0 && window[leftChar] < target[leftChar]) formed--;
                left++;
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(startIdx, startIdx + minLen);
    }
}
```
- **Time Complexity**: $O(m + n)$
- **Space Complexity**: $O(1)$ (128 ASCII array)

### 3.6 Sliding Window Maximum
- **Difficulty**: Hard
- **LeetCode**: [239. Sliding Window Maximum](https://leetcode.com/problems/sliding-window-maximum/)
- **NeetCode**: [Sliding Window Maximum](https://neetcode.io/problems/sliding-window-maximum)
- **Data Structures**: Array, Monotonic Deque
- **Patterns**: Monotonic Decreasing Deque

#### Problem Description
You are given an array of integers `nums`, there is a sliding window of size `k` which is moving from the very left of the array to the very right. You can only see the `k` numbers in the window. Each time the sliding window moves right by one position. Return the max sliding window.

#### Inputs & Outputs
- **Input**: `nums = [1,3,-1,-3,5,3,6,7]`, `k = 3` -> **Output**: `[3,3,5,5,6,7]`
- **Constraints**: `1 <= nums.length <= 10^5`, `-10^4 <= nums[i] <= 10^4`, `1 <= k <= nums.length`.

#### Solutions

##### Approach 1: Brute Force
Scan all $k$ elements in each of the $n - k + 1$ windows.
- **Time Complexity**: $O(n \cdot k)$
- **Space Complexity**: $O(1)$

##### Approach 2: Better (Max Heap / PriorityQueue)
Store `[val, index]` in a max-heap. Pop stale elements outside the window.
```java
import java.util.PriorityQueue;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n - k + 1];
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        for (int i = 0; i < n; i++) {
            pq.offer(new int[]{nums[i], i});
            while (pq.peek()[1] <= i - k) pq.poll();
            if (i >= k - 1) res[i - k + 1] = pq.peek()[0];
        }
        return res;
    }
}
```
- **Time Complexity**: $O(n \log n)$
- **Space Complexity**: $O(n)$

##### Approach 3: Optimised / Best (Monotonic Decreasing Deque)
Store indices in a `Deque`. Maintain strictly decreasing order by removing smaller elements from back before inserting. Front is always maximum.
```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n - k + 1];
        Deque<Integer> deque = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (!deque.isEmpty() && deque.peekFirst() <= i - k) {
                deque.pollFirst();
            }
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.pollLast();
            }
            deque.offerLast(i);
            if (i >= k - 1) {
                res[i - k + 1] = nums[deque.peekFirst()];
            }
        }
        return res;
    }
}
```
- **Time Complexity**: $O(n)$ (each element added and removed at most once)
- **Space Complexity**: $O(k)$

- **Data Structures**: Stack
- **Patterns**: Auxiliary Stack / Encoded Differences

#### Problem Description
Design a stack that supports `push`, `pop`, `top`, and retrieving the minimum element in constant time $O(1)$.

#### Solutions

##### Approach 1: Two Stacks
Maintain a main data stack and a min stack storing current minimum.
```java
import java.util.Stack;

class MinStack {
    private Stack<Integer> stack = new Stack<>();
    private Stack<Integer> minStack = new Stack<>();

    public MinStack() {}

    public void push(int val) {
        stack.push(val);
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }

    public void pop() {
        if (stack.peek().equals(minStack.peek())) {
            minStack.pop();
        }
        stack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

##### Approach 2: Best (Single Stack with Node Pair or Difference Encoding)
Store value and current minimum together in custom nodes.
```java
class MinStack {
    private static class Node {
        int val;
        int min;
        Node next;
        Node(int val, int min, Node next) {
            this.val = val;
            this.min = min;
            this.next = next;
        }
    }
    private Node head;

    public MinStack() {}

    public void push(int val) {
        if (head == null) head = new Node(val, val, null);
        else head = new Node(val, Math.min(val, head.min), head);
    }

    public void pop() {
        head = head.next;
    }

    public int top() {
        return head.val;
    }

    public int getMin() {
        return head.min;
    }
}
```

```java
class Solution {

                    top--;
                    break;

                    stack[top - 2] /= stack[top - 1];
```

- **Difficulty**: Medium

- **NeetCode**: [Generate Parentheses](https://neetcode.io/problems/generate-parentheses)
- **Data Structures**: String, Backtracking
- **Patterns**: Valid Prefix Pruning

#### Problem Description
Given `n` pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

#### Inputs & Outputs
- **Input**: `n = 3` -> **Output**: `["((()))","(()())","(())()","()(())","()()()"]`
- **Constraints**: `1 <= n <= 8`

#### Solutions

##### Approach 1: Optimised / Best (Backtracking with Open/Close Counts)
Add `'('` if `open < n`; add `')'` if `close < open`.
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        backtrack(res, new StringBuilder(), 0, 0, n);
        return res;
    }

    private void backtrack(List<String> res, StringBuilder sb, int open, int close, int max) {
        if (sb.length() == max * 2) {
            res.add(sb.toString());
            return;
        }
        if (open < max) {
            sb.append('(');
            backtrack(res, sb, open + 1, close, max);
            sb.deleteCharAt(sb.length() - 1);
        }
        if (close < open) {
            sb.append(')');
            backtrack(res, sb, open, close + 1, max);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
```
- **Time Complexity**: $O(\frac{4^n}{\sqrt{n}})$ ($n^{\text{th}}$ Catalan number)
- **Space Complexity**: $O(n)$ recursion stack

##### Approach 1: Monotonic Decreasing Stack
Push indices onto stack. When current temperature is higher than top, pop and compute day difference.

```java
import java.util.Stack;

class Solution {

        int n = temperatures.length;
        int[] res = new int[n];

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {

                res[prevDay] = i - prevDay;

        }
```

```java
class Solution {

                if (res[j] == 0) {
                    j = n; // no warmer day exists
                } else {
                    j += res[j];
                }
```

```java
import java.util.Arrays;
```

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;
        for (int i = 0; i <= n; i++) {
            int h = (i == n) ? 0 : heights[i];
            while (!stack.isEmpty() && h < heights[stack.peek()]) {
                int height = heights[stack.pop()];
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, height * width);
            }
            stack.push(i);
        }
        return maxArea;
    }
}
```

- **Difficulty**: Medium
- **LeetCode**: [74. Search a 2D Matrix](https://leetcode.com/problems/search-a-2d-matrix/)
- **NeetCode**: [Search 2D Matrix](https://neetcode.io/problems/search-2d-matrix)
- **Data Structures**: Array, Matrix
- **Patterns**: Virtual 1D Flattening

#### Problem Description
You are given an `m x n` integer matrix `matrix` with the properties:
1. Integers in each row are sorted from left to right.
2. The first integer of each row is greater than the last integer of the previous row.
Given an integer `target`, return `true` if `target` is in `matrix` or `false` otherwise.

#### Inputs & Outputs
- **Input**: `matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]`, `target = 3` -> **Output**: `true`
- **Constraints**: `m == matrix.length`, `n == matrix[i].length`, `1 <= m, n <= 100`

#### Solutions

##### Approach 1: Two-Step Binary Search (Row then Column)
Binary search the first column to locate the row, then binary search that row.
- **Time Complexity**: $O(\log m + \log n)$
- **Space Complexity**: $O(1)$

##### Approach 2: Optimised / Best (Virtual 1D Array Binary Search)
Treat matrix as a virtual 1D array of size $m \times n$. Coordinate mapping: `row = mid / n`, `col = mid % n`.
```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        int left = 0, right = m * n - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int val = matrix[mid / n][mid % n];
            if (val == target) return true;
            else if (val < target) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
```
- **Time Complexity**: $O(\log(m \cdot n))$
- **Space Complexity**: $O(1)$

### 5.3 Koko Eating Bananas
- **Difficulty**: Medium
- **LeetCode**: [875. Koko Eating Bananas](https://leetcode.com/problems/koko-eating-bananas/)
- **NeetCode**: [Eating Bananas](https://neetcode.io/problems/eating-bananas)
- **Data Structures**: Array
- **Patterns**: Binary Search on Solution Space

#### Problem Description
Koko loves to eat bananas. There are `n` piles of bananas, the $i^{\text{th}}$ pile has `piles[i]` bananas. The guards will come back in `h` hours. Koko can decide her bananas-per-hour eating speed of `k`. Each hour, she chooses some pile and eats `k` bananas from that pile. Return the minimum integer `k` such that she can eat all bananas within `h` hours.

#### Inputs & Outputs
- **Input**: `piles = [3,6,7,11]`, `h = 8` -> **Output**: `4`
- **Constraints**: `1 <= piles.length <= 10^4`, `piles.length <= h <= 10^9`, `1 <= piles[i] <= 10^9`

#### Solutions

##### Approach 1: Optimised / Best (Binary Search on Eating Speed)
Lower bound `left = 1`, upper bound `right = max(piles)`. If she can finish in $\le h$ hours, try a slower speed (`right = mid - 1`).
```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int left = 1, right = 1;
        for (int p : piles) right = Math.max(right, p);
        int ans = right;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            long hours = 0;
            for (int p : piles) {
                hours += (p + mid - 1) / mid;
            }
            if (hours <= h) {
                ans = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return ans;
    }
}
```
- **Time Complexity**: $O(n \log(\max(\text{piles})))$
- **Space Complexity**: $O(1)$

#### Problem Description
Given the array `nums` after the possible rotation and an integer `target`, return the index of `target` if it is in `nums`, or `-1` if it is not in `nums`. Algorithm must run in $O(\log n)$ time.

#### Inputs & Outputs
- **Input**: `nums = [4,5,6,7,0,1,2]`, `target = 0` -> **Output**: `4`
- **Input**: `nums = [4,5,6,7,0,1,2]`, `target = 3` -> **Output**: `-1`

#### Solutions

##### Approach 1: Optimised / Best (Sorted Half Elimination)
At any `mid`, at least one half (left or right) is guaranteed to be normally sorted. Check if `target` falls in the sorted half; if so, search there, else search the other half.
```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            if (nums[left] <= nums[mid]) { // Left half sorted
                if (target >= nums[left] && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else { // Right half sorted
                if (target > nums[mid] && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```
- **Time Complexity**: $O(\log n)$
- **Space Complexity**: $O(1)$

- **Patterns**: Hash Table + Binary Search on Timestamps

#### Problem Description
Design a time-based key-value data structure that can store multiple values for the same key at different time stamps and retrieve the key's value at a certain timestamp.
- `set(String key, String value, int timestamp)`: Stores key with value at timestamp.
- `get(String key, int timestamp)`: Returns value with largest `timestamp_prev <= timestamp`. If no such timestamp, returns `""`.

#### Solutions

##### Approach 1: Optimised / Best (HashMap + ArrayList + Binary Search)
Since timestamps in `set` are strictly increasing, each key's list is sorted by timestamp. Binary search `floor` timestamp in $O(\log n)$.
```java
import java.util.*;

class TimeMap {
    private static class Entry {
        int timestamp;
        String value;
        Entry(int timestamp, String value) {
            this.timestamp = timestamp;
            this.value = value;
        }
    }

    private Map<String, List<Entry>> map;

    public TimeMap() {
        map = new HashMap<>();
    }

    public void set(String key, String value, int timestamp) {
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(new Entry(timestamp, value));
    }

    public String get(String key, int timestamp) {
        if (!map.containsKey(key)) return "";
        List<Entry> list = map.get(key);
        int left = 0, right = list.size() - 1;
        String res = "";
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (list.get(mid).timestamp <= timestamp) {
                res = list.get(mid).value;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return res;
    }
}
```

### 5.7 Median of Two Sorted Arrays
- **Difficulty**: Hard
- **LeetCode**: [4. Median of Two Sorted Arrays](https://leetcode.com/problems/median-of-two-sorted-arrays/)
- **NeetCode**: [Median of Two Sorted Arrays](https://neetcode.io/problems/median-of-two-sorted-arrays)
- **Data Structures**: Array, Binary Search
- **Patterns**: Partition Binary Search

#### Problem Description
Given two sorted arrays `nums1` and `nums2` of size `m` and `n` respectively, return the median of the two sorted arrays. The overall run time complexity should be $O(\log(m+n))$.

#### Inputs & Outputs
- **Input**: `nums1 = [1,3]`, `nums2 = [2]` -> **Output**: `2.0`
- **Input**: `nums1 = [1,2]`, `nums2 = [3,4]` -> **Output**: `2.5`
- **Constraints**: `0 <= m, n <= 1000`, `1 <= m + n <= 2000`

#### Solutions

##### Approach 1: Brute Force (Merge Arrays)
Merge two arrays into a single sorted array of size $m + n$ and take middle element(s).
- **Time Complexity**: $O(m + n)$
- **Space Complexity**: $O(m + n)$

##### Approach 2: Optimised / Best (Binary Search on Smaller Array Partition)
Binary search the partition index `i` in smaller array `nums1` and compute `j = (m + n + 1) / 2 - i`. Partition is valid if `nums1[i-1] <= nums2[j]` and `nums2[j-1] <= nums1[i]`.
```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }
        int m = nums1.length, n = nums2.length;
        int left = 0, right = m;
        while (left <= right) {
            int i = left + (right - left) / 2;
            int j = (m + n + 1) / 2 - i;
            int maxLeft1 = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int minRight1 = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int maxLeft2 = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int minRight2 = (j == n) ? Integer.MAX_VALUE : nums2[j];

            if (maxLeft1 <= minRight2 && maxLeft2 <= minRight1) {
                if ((m + n) % 2 == 1) {
                    return Math.max(maxLeft1, maxLeft2);
                } else {
                    return (Math.max(maxLeft1, maxLeft2) + Math.min(minRight1, minRight2)) / 2.0;
                }
            } else if (maxLeft1 > minRight2) {
                right = i - 1;
            } else {
                left = i + 1;
            }
        }
        return 0.0;
    }
}
```
- **Time Complexity**: $O(\log(\min(m, n)))$
- **Space Complexity**: $O(1)$

### 6.9 LRU Cache
- **Difficulty**: Medium
- **LeetCode**: [146. LRU Cache](https://leetcode.com/problems/lru-cache/)
- **NeetCode**: [LRU Cache](https://neetcode.io/problems/lru-cache)
- **Data Structures**: Hash Table, Doubly Linked List
- **Patterns**: Hash Table + Doubly Linked List

#### Solutions

##### Approach 1: Optimised / Best (HashMap + Doubly Linked List)
```java
import java.util.HashMap;
import java.util.Map;

class LRUCache {
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int key, int val) { this.key = key; this.val = val; }
    }

    private final int capacity;
    private final Map<Integer, Node> map;
    private final Node head, tail;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.map = new HashMap<>();
        head = new Node(0, 0);
        tail = new Node(0, 0);
        head.next = tail;
        tail.prev = head;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void insertToHead(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        Node node = map.get(key);
        remove(node);
        insertToHead(node);
        return node.val;
    }

    public void put(int key, int value) {
        if (map.containsKey(key)) {
            Node node = map.get(key);
            node.val = value;
            remove(node);
            insertToHead(node);
        } else {
            if (map.size() == capacity) {
                Node lru = tail.prev;
                remove(lru);
                map.remove(lru.key);
            }
            Node newNode = new Node(key, value);
            map.put(key, newNode);
            insertToHead(newNode);
        }
    }
}
```
- **Time Complexity**: $O(1)$ for both `get` and `put`
- **Space Complexity**: $O(\text{capacity})$

```java
        if (lists == null || lists.length == 0) return null;
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
        for (ListNode node : lists) {
            if (node != null) pq.offer(node);
        }
        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;
        while (!pq.isEmpty()) {
            ListNode minNode = pq.poll();
            curr.next = minNode;
            curr = curr.next;
            if (minNode.next != null) pq.offer(minNode.next);
        }
        return dummy.next;
    }
}
```
- **Time Complexity**: $O(N \log k)$
- **Space Complexity**: $O(k)$

##### Approach 2: Best (Divide and Conquer Merge Sort)
Merge pairs iteratively in-place.
```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;
        int interval = 1;
        while (interval < lists.length) {
            for (int i = 0; i + interval < lists.length; i += interval * 2) {
                lists[i] = mergeTwo(lists[i], lists[i + interval]);
            }
            interval *= 2;
        }
        return lists[0];
    }

    private ListNode mergeTwo(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) { curr.next = l1; l1 = l1.next; }
            else { curr.next = l2; l2 = l2.next; }
            curr = curr.next;
        }
        curr.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```
- **Time Complexity**: $O(N \log k)$
- **Space Complexity**: $O(1)$

```java
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode groupPrev = dummy;
        while (true) {
            ListNode kth = getKth(groupPrev, k);

            ListNode groupNext = kth.next;

            groupPrev = tmp;
        }

        }
```

```java
    private final PriorityQueue<Integer> minHeap;
    private final int k;

    public KthLargest(int k, int[] nums) {
        this.k = k;
```

```java
        return minHeap.peek();
    }
}
```
- **Time Complexity**: $O(n \log k)$
- **Space Complexity**: $O(k)$

##### Approach 2: Best (QuickSelect / Hoare's Selection Algorithm)
```java
import java.util.Random;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        int targetIdx = nums.length - k;
        return quickSelect(nums, 0, nums.length - 1, targetIdx);
    }

    private int quickSelect(int[] nums, int left, int right, int k) {
        if (left == right) return nums[left];
        int pivotIndex = left + new Random().nextInt(right - left + 1);
        pivotIndex = partition(nums, left, right, pivotIndex);
        if (pivotIndex == k) return nums[k];
        else if (pivotIndex < k) return quickSelect(nums, pivotIndex + 1, right, k);
        else return quickSelect(nums, left, pivotIndex - 1, k);
    }

    private int partition(int[] nums, int left, int right, int pivotIndex) {
        int pivot = nums[pivotIndex];
        swap(nums, pivotIndex, right);
        int storeIdx = left;
        for (int i = left; i < right; i++) {
            if (nums[i] < pivot) {
                swap(nums, storeIdx, i);
                storeIdx++;
            }
        }
        swap(nums, storeIdx, right);
        return storeIdx;
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i]; nums[i] = nums[j]; nums[j] = tmp;
    }
}
```
- **Time Complexity**: Average $O(n)$, Worst $O(n^2)$
- **Space Complexity**: $O(1)$ auxiliary

##### Approach 1: Optimised / Best (Greedy Math Formula)
The task with the maximum frequency `maxFreq` forms `(maxFreq - 1)` chunks of size `(n + 1)`. Total slots = $\max(\text{tasks.length}, (\text{maxFreq} - 1) \times (n + 1) + \text{countMaxFreq})$.
```java
class Solution {

        int[] count = new int[26];
        int maxFreq = 0;
        for (char c : tasks) {
            count[c - 'A']++;
            maxFreq = Math.max(maxFreq, count[c - 'A']);
        }
        int maxCount = 0;
        for (int c : count) {
            if (c == maxFreq) maxCount++;
        }
        int emptySlots = (maxFreq - 1) * (n + 1) + maxCount;
        return Math.max(tasks.length, emptySlots);
    }
}
```

```java
    private static class Tweet {
        int id, time;
        Tweet next;
        Tweet(int id, int time) { this.id = id; this.time = time; }
    }

    private static class User {
        int id;
        Set<Integer> followed;
        Tweet tweetHead;
        User(int id) {
            this.id = id;
            followed = new HashSet<>();
            follow(id); // Follow self
        }
        void follow(int id) { followed.add(id); }
        void unfollow(int id) { followed.remove(id); }
        void post(int id) {
            Tweet t = new Tweet(id, timestamp++);
            t.next = tweetHead;
            tweetHead = t;
        }

    private Map<Integer, User> userMap = new HashMap<>();

    public Twitter() {}

    public void postTweet(int userId, int tweetId) {

        List<Integer> res = new ArrayList<>();
        if (!userMap.containsKey(userId)) return res;
        Set<Integer> users = userMap.get(userId).followed;
        PriorityQueue<Tweet> pq = new PriorityQueue<>((a, b) -> b.time - a.time);
        for (int uid : users) {
            User u = userMap.get(uid);
            if (u != null && u.tweetHead != null) {
                pq.offer(u.tweetHead);
            }
        }
        int count = 0;
        while (!pq.isEmpty() && count < 10) {
            Tweet t = pq.poll();
            res.add(t.id);
            count++;
            if (t.next != null) pq.offer(t.next);
        }
        return res;
    }

    public void follow(int followerId, int followeeId) {
        userMap.computeIfAbsent(followerId, User::new);
        userMap.computeIfAbsent(followeeId, User::new);
        userMap.get(followerId).follow(followeeId);
    }

    public void unfollow(int followerId, int followeeId) {
        if (userMap.containsKey(followerId) && followerId != followeeId) {
            userMap.get(followerId).unfollow(followeeId);
        }
    }
}
```

```java
    private PriorityQueue<Integer> large; // Min-heap (stores larger half)

    public MedianFinder() {
        small = new PriorityQueue<>((a, b) -> b - a);
        large = new PriorityQueue<>();
    }

    public void addNum(int num) {
        small.offer(num);
        large.offer(small.poll());
        if (large.size() > small.size()) {
            small.offer(large.poll());
        }
    }

        if (small.size() > large.size()) {
            return small.peek();
        } else {

        }
```

```java
        backtrack(nums, 0, res);
        return res;
```

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (board[r][c] == word.charAt(0) && dfs(board, r, c, word, 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, int r, int c, String word, int idx) {
        if (idx == word.length()) return true;
        if (r < 0 || r >= board.length || c < 0 || c >= board[0].length || board[r][c] != word.charAt(idx)) {
            return false;
        }
        char temp = board[r][c];
        board[r][c] = '#'; // Mark visited
        boolean found = dfs(board, r + 1, c, word, idx + 1) ||
                        dfs(board, r - 1, c, word, idx + 1) ||
                        dfs(board, r, c + 1, word, idx + 1) ||
                        dfs(board, r, c - 1, word, idx + 1);
        board[r][c] = temp; // Backtrack
        return found;
    }
}
```

```java
import java.util.*;

class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> res = new ArrayList<>();
        char[][] board = new char[n][n];
        for (char[] row : board) Arrays.fill(row, '.');
        boolean[] cols = new boolean[n];
        boolean[] diag1 = new boolean[2 * n]; // r - c + n
        boolean[] diag2 = new boolean[2 * n]; // r + c
        backtrack(0, n, board, cols, diag1, diag2, res);
        return res;
    }

    private void backtrack(int r, int n, char[][] board, boolean[] cols, boolean[] d1, boolean[] d2, List<List<String>> res) {

            List<String> list = new ArrayList<>();
            for (char[] row : board) list.add(new String(row));
            res.add(list);
            return;

        for (int c = 0; c < n; c++) {

            board[r][c] = 'Q';
            cols[c] = d1[r - c + n] = d2[r + c] = true;
            backtrack(r + 1, n, board, cols, d1, d2, res);
            board[r][c] = '.';
            cols[c] = d1[r - c + n] = d2[r + c] = false;
        }
    }
```

```java
class Trie {
    private static class Node {
        Node[] children = new Node[26];
        boolean isEnd = false;
    }

    private final Node root;

    public Trie() {
        root = new Node();
    }

    public void insert(String word) {
        Node curr = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) {
                curr.children[idx] = new Node();
            }
            curr = curr.children[idx];
        }
        curr.isEnd = true;
    }

    public boolean search(String word) {
        Node node = find(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    private Node find(String s) {
        Node curr = root;
        for (char c : s.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) return null;
            curr = curr.children[idx];
        }
        return curr;
    }
}
```

#### Solutions

##### Approach 1: Optimised / Best (Trie + DFS for Wildcards)
```java
class WordDictionary {
    private static class Node {
        Node[] children = new Node[26];
        boolean isEnd = false;
    }

    private final Node root;

    public WordDictionary() {
        root = new Node();
    }

    public void addWord(String word) {
        Node curr = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) curr.children[idx] = new Node();
            curr = curr.children[idx];
        }
        curr.isEnd = true;
    }

    public boolean search(String word) {
        return match(word, 0, root);
    }

    private boolean match(String word, int idx, Node node) {
        if (node == null) return false;
        if (idx == word.length()) return node.isEnd;
        char c = word.charAt(idx);
        if (c == '.') {
            for (Node child : node.children) {
                if (child != null && match(word, idx + 1, child)) return true;
            }
            return false;
        } else {
            return match(word, idx + 1, node.children[c - 'a']);
        }
    }
}
```

```java
import java.util.*;

class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word = null;
    }

    public List<String> findWords(char[][] board, String[] words) {
        TrieNode root = new TrieNode();
        for (String w : words) {
            TrieNode curr = root;
            for (char c : w.toCharArray()) {
                int idx = c - 'a';
                if (curr.children[idx] == null) curr.children[idx] = new TrieNode();
                curr = curr.children[idx];
            }
            curr.word = w;
        }

        List<String> res = new ArrayList<>();
        int m = board.length, n = board[0].length;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                dfs(board, r, c, root, res);
            }
        }
        return res;
    }

    private void dfs(char[][] board, int r, int c, TrieNode node, List<String> res) {
        if (r < 0 || r >= board.length || c < 0 || c >= board[0].length || board[r][c] == '#') return;
        char ch = board[r][c];
        int idx = ch - 'a';
        if (node.children[idx] == null) return;
        TrieNode nextNode = node.children[idx];
        if (nextNode.word != null) {
            res.add(nextNode.word);
            nextNode.word = null; // Prevent duplicates
        }

        board[r][c] = '#';
        dfs(board, r + 1, c, nextNode, res);
        dfs(board, r - 1, c, nextNode, res);
        dfs(board, r, c + 1, nextNode, res);
        dfs(board, r, c - 1, nextNode, res);
        board[r][c] = ch;
    }
}
```

```java
                        queue.offer(new int[]{nr, nc});
```

```java
                }
            }
            minutes++;
        }
```

```java
        Set<String> wordSet = new HashSet<>(wordList);

        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);

                        }

                    curr[j] = orig;
                }
            }
            level++;
        }
        return 0;
```

```java
        return Math.max(robSimple(nums, 0, nums.length - 2), robSimple(nums, 1, nums.length - 1));
```

```java
        if (s == null || s.length() < 1) return "";
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            int len1 = expand(s, i, i);     // Odd length

        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

### 13.7 Longest Increasing Path in a Matrix
- **Difficulty**: Hard
- **LeetCode**: [329. Longest Increasing Path in a Matrix](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)
- **NeetCode**: [Longest Increasing Path in Matrix](https://neetcode.io/problems/longest-increasing-path-in-matrix)
- **Data Structures**: Matrix, DFS with Memoization
- **Patterns**: DFS + Memoization (DAG Traversal)

#### Solutions

##### Approach 1: Optimised / Best (DFS with Memoization)
Since path is strictly increasing, cycles are impossible; the grid forms a DAG.
```java
class Solution {
    private int[][] memo;
    private int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    public int longestIncreasingPath(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        memo = new int[m][n];
        int maxLen = 0;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                maxLen = Math.max(maxLen, dfs(matrix, r, c));
            }
        }
        return maxLen;
    }

    private int dfs(int[][] matrix, int r, int c) {
        if (memo[r][c] != 0) return memo[r][c];
        int max = 1;
        for (int[] d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr >= 0 && nr < matrix.length && nc >= 0 && nc < matrix[0].length && matrix[nr][nc] > matrix[r][c]) {
                max = Math.max(max, 1 + dfs(matrix, nr, nc));
            }
        }
        return memo[r][c] = max;
    }
}
```
- **Time Complexity**: $O(m \cdot n)$
- **Space Complexity**: $O(m \cdot n)$

### 15.6 Minimum Interval to Include Each Query
- **Difficulty**: Hard
- **LeetCode**: [1851. Minimum Interval to Include Each Query](https://leetcode.com/problems/minimum-interval-to-include-each-query/)
- **NeetCode**: [Minimum Interval Including Query](https://neetcode.io/problems/minimum-interval-including-query)
- **Data Structures**: Min-Heap, Sorting
- **Patterns**: Offline Queries + Min-Heap Sweep-Line

#### Solutions

##### Approach 1: Optimised / Best (Sorted Queries + PriorityQueue)
Sort intervals and queries. Use min-heap ordered by interval size. Remove intervals that end before current query.
```java
import java.util.*;

class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        int qLen = queries.length;
        int[][] sortedQ = new int[qLen][2];
        for (int i = 0; i < qLen; i++) {
            sortedQ[i][0] = queries[i];
            sortedQ[i][1] = i;
        }
        Arrays.sort(sortedQ, (a, b) -> Integer.compare(a[0], b[0]));

        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
        int[] res = new int[qLen];
        int i = 0;
        for (int[] q : sortedQ) {
            int qVal = q[0], qIdx = q[1];
            while (i < intervals.length && intervals[i][0] <= qVal) {
                int left = intervals[i][0], right = intervals[i][1];
                minHeap.offer(new int[]{right - left + 1, right});
                i++;
            }
            while (!minHeap.isEmpty() && minHeap.peek()[1] < qVal) {
                minHeap.poll();
            }
            res[qIdx] = minHeap.isEmpty() ? -1 : minHeap.peek()[0];
        }
        return res;
    }
}
```
- **Time Complexity**: $O(N \log N + Q \log Q)$
- **Space Complexity**: $O(N + Q)$

### 16.8 Detect Squares
- **Difficulty**: Medium

#### Solutions

##### Approach 1: Optimised / Best (Diagonal Corner Matching)
```java
import java.util.*;

class DetectSquares {
    private int[][] counts = new int[1001][1001];
    private List<int[]> points = new ArrayList<>();

    public DetectSquares() {}

    public void add(int[] point) {
        counts[point[0]][point[1]]++;
        points.add(point);
    }

    public int count(int[] point) {
        int x1 = point[0], y1 = point[1];
        int totalSquares = 0;
        for (int[] p : points) {
            int x3 = p[0], y3 = p[1];
            if (Math.abs(x1 - x3) == 0 || Math.abs(x1 - x3) != Math.abs(y1 - y3)) {
                continue; // Not a valid non-zero diagonal
            }
            totalSquares += counts[x1][y3] * counts[x3][y1];
        }
        return totalSquares;
    }
```

- **NeetCode**: [Min Cost to Connect Points](https://neetcode.io/problems/min-cost-to-connect-points)

- **Patterns**: Prim's Algorithm / Kruskal's with DSU

##### Approach 1: Optimised / Best (Prim's Algorithm with Array Tracking)

```java
class Solution {
    public int minCostConnectPoints(int[][] points) {
        int n = points.length;
        int[] minDist = new int[n];
        for (int i = 1; i < n; i++) minDist[i] = Integer.MAX_VALUE;
        boolean[] visited = new boolean[n];
        int totalCost = 0;

        for (int step = 0; step < n; step++) {
            int u = -1;
            for (int i = 0; i < n; i++) {
                if (!visited[i] && (u == -1 || minDist[i] < minDist[u])) {
                    u = i;
                }
            }
            visited[u] = true;
            totalCost += minDist[u];
            for (int v = 0; v < n; v++) {
                if (!visited[v]) {
                    int dist = Math.abs(points[u][0] - points[v][0]) + Math.abs(points[u][1] - points[v][1]);
                    minDist[v] = Math.min(minDist[v], dist);
                }
            }
        }
        return totalCost;
    }
}
```

- **Difficulty**: Medium
- **LeetCode**: [743. Network Delay Time](https://leetcode.com/problems/network-delay-time/)

- **Patterns**: Dijkstra's Shortest Path Algorithm

##### Approach 1: Optimised / Best (Dijkstra's Algorithm)
```java
import java.util.*;

class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        Map<Integer, List<int[]>> adj = new HashMap<>();
        for (int[] t : times) {
            adj.computeIfAbsent(t[0], x -> new ArrayList<>()).add(new int[]{t[1], t[2]});
        }
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
        pq.offer(new int[]{k, 0});
        Map<Integer, Integer> dist = new HashMap<>();

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int u = curr[0], d = curr[1];
            if (dist.containsKey(u)) continue;
            dist.put(u, d);
            if (adj.containsKey(u)) {
                for (int[] edge : adj.get(u)) {
                    int v = edge[0], weight = edge[1];
                    if (!dist.containsKey(v)) {
                        pq.offer(new int[]{v, d + weight});
                    }
                }
            }
        }
        if (dist.size() != n) return -1;
        int maxDist = 0;
        for (int d : dist.values()) maxDist = Math.max(maxDist, d);
        return maxDist;
    }
}
```

```java
import java.util.PriorityQueue;

class Solution {
    public int swimInWater(int[][] grid) {
        int n = grid.length;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[2] - b[2]);
        boolean[][] visited = new boolean[n][n];
        pq.offer(new int[]{0, 0, grid[0][0]});
        visited[0][0] = true;
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int r = curr[0], c = curr[1], maxWater = curr[2];
            if (r == n - 1 && c == n - 1) return maxWater;
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < n && nc >= 0 && nc < n && !visited[nr][nc]) {
                    visited[nr][nc] = true;
                    pq.offer(new int[]{nr, nc, Math.max(maxWater, grid[nr][nc])});
                }
            }
        }
        return -1;
    }
}
```

### 18.5 Alien Dictionary
- **Difficulty**: Hard
- **LeetCode**: [269. Alien Dictionary](https://leetcode.com/problems/alien-dictionary/)
- **NeetCode**: [Foreign Dictionary](https://neetcode.io/problems/foreign-dictionary)
- **Data Structures**: Graph, Topological Sort
- **Patterns**: Directed Graph Topological Sort (Kahn's or DFS)

#### Solutions

##### Approach 1: Optimised / Best (Kahn's Algorithm with Prefix Edge Validation)
```java
import java.util.*;

class Solution {
    public String foreignDictionary(String[] words) {
        Map<Character, Set<Character>> adj = new HashMap<>();
        Map<Character, Integer> inDegree = new HashMap<>();
        for (String w : words) {
            for (char c : w.toCharArray()) inDegree.put(c, 0);
        }

        for (int i = 0; i < words.length - 1; i++) {
            String w1 = words[i], w2 = words[i + 1];
            if (w1.length() > w2.length() && w1.startsWith(w2)) return ""; // Invalid prefix order
            for (int j = 0; j < Math.min(w1.length(), w2.length()); j++) {
                char c1 = w1.charAt(j), c2 = w2.charAt(j);
                if (c1 != c2) {
                    adj.computeIfAbsent(c1, k -> new HashSet<>());
                    if (adj.get(c1).add(c2)) {
                        inDegree.put(c2, inDegree.get(c2) + 1);
                    }
                    break;
                }
            }
        }

        Queue<Character> queue = new LinkedList<>();
        for (char c : inDegree.keySet()) {
            if (inDegree.get(c) == 0) queue.offer(c);
        }

        StringBuilder sb = new StringBuilder();
        while (!queue.isEmpty()) {
            char curr = queue.poll();
            sb.append(curr);
            if (adj.containsKey(curr)) {
                for (char next : adj.get(curr)) {
                    inDegree.put(next, inDegree.get(next) - 1);
                    if (inDegree.get(next) == 0) queue.offer(next);
                }
            }
        }

        return sb.length() == inDegree.size() ? sb.toString() : "";
    }
}
```
- **Time Complexity**: $O(C)$ where $C$ is total characters in all words
- **Space Complexity**: $O(1)$ (at most 26 characters)

```java
    public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
        int[] prices = new int[n];
        Arrays.fill(prices, Integer.MAX_VALUE);
        prices[src] = 0;
```

```java
                    cond.await();
                }
                if (curr > n) return;
                printFizz.run();
                curr++;
                cond.signalAll();
            } finally {
                lock.unlock();
            }
        }
    }

    public void buzz(Runnable printBuzz) throws InterruptedException {
        while (true) {
            lock.lock();
            try {
                while (curr <= n && !(curr % 5 == 0 && curr % 3 != 0)) {
                    cond.await();
                }
                if (curr > n) return;
                printBuzz.run();
                curr++;
                cond.signalAll();
            } finally {
                lock.unlock();
            }
        }
    }

    public void fizzbuzz(Runnable printFizzBuzz) throws InterruptedException {
        while (true) {
            lock.lock();
            try {
                while (curr <= n && !(curr % 15 == 0)) {
                    cond.await();
                }
                if (curr > n) return;
                printFizzBuzz.run();
                curr++;
                cond.signalAll();
            } finally {
                lock.unlock();
            }
        }
    }

    public void number(IntConsumer printNumber) throws InterruptedException {
        while (true) {
            lock.lock();
            try {
                while (curr <= n && (curr % 3 == 0 || curr % 5 == 0)) {
                    cond.await();
                }
                if (curr > n) return;
                printNumber.accept(curr);
                curr++;
                cond.signalAll();
            } finally {
                lock.unlock();
            }
        }
    }
}
```
- **Time Complexity**: $O(n)$

### 20.6 The Dining Philosophers
- **Difficulty**: Medium
- **LeetCode**: [1226. The Dining Philosophers](https://leetcode.com/problems/the-dining-philosophers/)
- **Data Structures**: Concurrency
- **Patterns**: Resource Hierarchy / Global Mutex / Semaphores

#### Solutions

##### Approach 1: Resource Ordering (Asymmetric Fork Picking)
Philosopher with odd ID picks left fork first; even ID picks right fork first to prevent circular wait deadlock.
```java
import java.util.concurrent.locks.ReentrantLock;

class DiningPhilosophers {
    private ReentrantLock[] forks = new ReentrantLock[5];

    public DiningPhilosophers() {
        for (int i = 0; i < 5; i++) {
            forks[i] = new ReentrantLock();
        }
    }

    public void wantsToEat(int philosopher,
                           Runnable pickLeftFork,
                           Runnable pickRightFork,
                           Runnable eat,
                           Runnable putLeftFork,
                           Runnable putRightFork) throws InterruptedException {
        int left = philosopher;
        int right = (philosopher + 1) % 5;

        // Resource hierarchy: always pick lower numbered lock first
        int first = Math.min(left, right);
        int second = Math.max(left, right);

        forks[first].lock();
        forks[second].lock();
        try {
            pickLeftFork.run();
            pickRightFork.run();
            eat.run();
            putLeftFork.run();
            putRightFork.run();
        } finally {
            forks[second].unlock();
            forks[first].unlock();
        }
    }
}
```
- **Time Complexity**: $O(1)$ per eat operation
- **Space Complexity**: $O(1)$

### 20.7 Design Bounded Blocking Queue
- **Difficulty**: Medium
- **LeetCode**: [1188. Design Bounded Blocking Queue](https://leetcode.com/problems/design-bounded-blocking-queue/)
- **Data Structures**: Queue, Concurrency
- **Patterns**: Producer-Consumer with ReentrantLock & Conditions

#### Solutions

##### Approach 1: Optimised / Best (Circular Array + Two Conditions)
```java
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

class BoundedBlockingQueue {
    private int[] elements;
    private int head = 0, tail = 0, size = 0, capacity;
    private ReentrantLock lock = new ReentrantLock();
    private Condition notFull = lock.newCondition();
    private Condition notEmpty = lock.newCondition();

    public BoundedBlockingQueue(int capacity) {
        this.capacity = capacity;
        this.elements = new int[capacity];
    }

    public void enqueue(int element) throws InterruptedException {
        lock.lock();
        try {
            while (size == capacity) {
                notFull.await();
            }
            elements[tail] = element;
            tail = (tail + 1) % capacity;
            size++;
            notEmpty.signal();
        } finally {
            lock.unlock();
        }
    }

    public int dequeue() throws InterruptedException {
        lock.lock();
        try {
            while (size == 0) {
                notEmpty.await();
            }
            int val = elements[head];
            head = (head + 1) % capacity;
            size--;
            notFull.signal();
            return val;
        } finally {
            lock.unlock();
        }
    }

    public int size() {
        lock.lock();
        try {
            return size;
        } finally {
            lock.unlock();
        }
    }
}
```
- **Time Complexity**: $O(1)$ for `enqueue`, `dequeue`, and `size`
- **Space Complexity**: $O(\text{capacity})$

### 20.9 LFU Cache
- **Difficulty**: Hard
- **LeetCode**: [460. LFU Cache](https://leetcode.com/problems/lfu-cache/)
- **Data Structures**: Hash Table, Doubly Linked List
- **Patterns**: Frequency-to-DoublyLinkedList Hash Map

#### Solutions

##### Approach 1: Optimised / Best (Two HashMaps + Doubly Linked Lists)
Maintain `keyToVal`, `keyToCount`, `countToLRU`, and `minFreq`.
```java
import java.util.*;

class LFUCache {
    private static class Node {
        int key, val, count;
        Node prev, next;
        Node(int key, int val) {
            this.key = key;
            this.val = val;
            this.count = 1;
        }
    }

    private static class DLList {
        Node head, tail;
        int size = 0;
        DLList() {
            head = new Node(0, 0);
            tail = new Node(0, 0);
            head.next = tail;
            tail.prev = head;
        }
        void add(Node node) {
            node.next = head.next;
            node.prev = head;
            head.next.prev = node;
            head.next = node;
            size++;
        }
        void remove(Node node) {
            node.prev.next = node.next;
            node.next.prev = node.prev;
            size--;
        }
        Node removeLast() {
            if (size > 0) {
                Node node = tail.prev;
                remove(node);
                return node;
            }
            return null;
        }
    }

    private final int capacity;
    private int minFreq = 0;
    private final Map<Integer, Node> nodeMap = new HashMap<>();
    private final Map<Integer, DLList> countMap = new HashMap<>();

    public LFUCache(int capacity) {
        this.capacity = capacity;
    }

    public int get(int key) {
        Node node = nodeMap.get(key);
        if (node == null) return -1;
        update(node);
        return node.val;
    }

    public void put(int key, int value) {
        if (capacity == 0) return;
        if (nodeMap.containsKey(key)) {
            Node node = nodeMap.get(key);
            node.val = value;
            update(node);
        } else {
            if (nodeMap.size() == capacity) {
                DLList minList = countMap.get(minFreq);
                Node removed = minList.removeLast();
                nodeMap.remove(removed.key);
            }
            Node newNode = new Node(key, value);
            nodeMap.put(key, newNode);
            minFreq = 1;
            countMap.computeIfAbsent(1, k -> new DLList()).add(newNode);
        }
    }

    private void update(Node node) {
        DLList oldList = countMap.get(node.count);
        oldList.remove(node);
        if (node.count == minFreq && oldList.size == 0) {
            minFreq++;
        }
        node.count++;
        countMap.computeIfAbsent(node.count, k -> new DLList()).add(node);
    }
}
```
- **Time Complexity**: $O(1)$ for both `get` and `put`
- **Space Complexity**: $O(\text{capacity})$

### 20.10 Design Hit Counter
- **Difficulty**: Medium
- **LeetCode**: [362. Design Hit Counter](https://leetcode.com/problems/design-hit-counter/)
- **Data Structures**: Queue / Fixed Circular Arrays
- **Patterns**: Circular Ring Buffer of 300 Seconds

#### Solutions

##### Approach 1: Optimised / Best (Circular Fixed Array of Size 300)
```java
class HitCounter {
    private int[] times;
    private int[] hits;

    public HitCounter() {
        times = new int[300];
        hits = new int[300];
    }

    public void hit(int timestamp) {
        int idx = timestamp % 300;
        if (times[idx] != timestamp) {
            times[idx] = timestamp;
            hits[idx] = 1;
        } else {
            hits[idx]++;
        }
    }

    public int getHits(int timestamp) {
        int total = 0;
        for (int i = 0; i < 300; i++) {
            if (timestamp - times[i] < 300) {
                total += hits[i];
            }
        }
        return total;
    }
}
```
- **Time Complexity**: `hit`: $O(1)$, `getHits`: $O(300) = O(1)$
- **Space Complexity**: $O(1)$ (constant 300 integers)
